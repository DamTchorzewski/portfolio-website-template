SUW Manager App

SUW Manager is a specialized application for water treatment stations, designed for service management, operational analysis, cost monitoring, and system supervision.

Back to Projects

Project Overview

The project was focused on delivering reliable interfaces for operators, technicians, and service teams managing water treatment infrastructure in daily operations.

  • Web Interfaces (React + TypeScript)

    Designed and developed complete web interfaces using React and TypeScript.

  • Desktop Application (Electron.js)

    Implemented and maintained the desktop application with Electron.js.

  • Operational Dashboards

    Designed and built analytical dashboards to monitor station performance.

  • Backend Integration

    Integrated applications with backend services via REST API and Swagger/OpenAPI.

  • Security, Accessibility, and Responsiveness

    Ensured high security, accessibility, and responsive design across views.

  • UX Optimization for Field Teams

    Optimized interfaces and user experience for field technicians and operators.

  • Cross-Team Collaboration

    Collaborated closely with backend and industrial automation teams.

Unique Project Features:

  • Industrial Context Awareness:

    Designed with real operational workflows and station constraints in mind.

  • Component Architecture:

    Reusable modules improved consistency, maintainability, and release speed.

  • Data-Driven Supervision:

    Enabled clear monitoring of operational status, costs, and service activities.

Project Outcomes:

  • Improved visibility of operational data for technical and management teams.
  • Reduced friction in service planning and maintenance communication.
  • Delivered a scalable foundation for future modules and station expansions.
